# Health Passport

A privacy-first Personal Health Passport that uses local AI to transform
unstructured clinical notes into structured medical information and
patient-friendly summaries.

## Features

- Biomedical entity extraction (scispaCy)
- UMLS entity linking
- Semantic type classification
- Negation detection
- Local LLM summarisation
- Personal health dashboard (planned)

## Tech Stack

- Python
- scispaCy
- UMLS
- Ollama
- ASP.NET Core
- Blazor
- SQL Server
