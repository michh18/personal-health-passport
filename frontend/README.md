# Personal Health Passport Frontend

The React frontend for the Personal Health Passport project.

The application will provide a privacy-first interface for transforming
unstructured clinical letters into an organised, portable medical history.

## Current features

- Clinical notes text input
- Local display of submitted notes
- Responsive light and dark styling

The backend integration has not been implemented yet.

Requirements:

- Node.js
- npm
